- **TopCoach:** amaliy student ish muhiti; ariza, yozish, vazifa va hujjatni bog‘lash; profil hamda tayyorgarlikning keyingi ishlarini ko‘rsatish. Menyuda student workspace, o‘qish va community alohida guruhlar. [TopCoach](https://topcoachuni.com/)
- **CollegeBase:** Home/Profile, Essentials, Prepare va Apply guruhlari; o‘z insholarini yozish bilan namunalar kutubxonasini ajratish. [CollegeBase](https://www.collegebase.org/)
- **IELTS Nation / Ibrat:** tayyorgarlikning tushunarli yo‘li va kichik, qulay kartalar. IELTS bo‘yicha batafsil kuzatuvlar oldingi hujjatda. [IELTS Nation](https://www.ieltsnation.com/), [Ibrat](https://ibratfarzandlari.uz/)

Motivatsion dashboard jumlalari, maskotning nutq pufagi va animatsiya tugmasi olib tashlandi. Landing matnlari mavjud vositalarni tushuntiradi; soxta ball o‘sishi va portfolio ulashish va’dalari chiqarildi.

Logo `sirius-identity-original.png`dagi **asl rasmni** ko‘rsatadi: bosh va yuqori qism CSS orqali ko‘rinish chegarasiga joylashtiriladi. Rasm fayli qayta chizilmagan. ## Admin chegarasi

`/admin/login` Google kirishi orqali `/admin`ga olib boradi. Panel kirish paytida bazadagi joriy rolni qayta tekshiradi. Student menyusida kontent/analitika havolalari yo‘q. EDITOR kontent bilan ishlaydi; ADMIN analitikaga ham kiradi. Oddiy student kontent paneliga murojaat qilsa 404, analitika eksportida 403 oladi. Kirilmagan yoki qalbaki session admin loginiga qaytadi. Oldingi `/content` va `/analytics` manzillari ham himoyalangan.

Kontent oqimi: JSON preview → validatsiya → import → tekshirish → nashr. Savollar borligi ularning o‘qituvchi tomonidan tasdiqlanganini anglatmaydi. Hozir teacher/reviewer aniqlanmagan. Admin faqat foydalanuvchi tasdiqlagan `dev/sirius` hisobiga berilgan; kalitlar va connection string GitHubga kiritilmagan.

## Keyingi ishlar: ketma-ket, tugash sharti bilan

1. **UI va ishlab chiqarish muhitini yakunlash.** Hozirgi checkpointni ko‘rib chiqish; 320/390/tablet/desktop oqimlar, keyboard, empty/error/loading holatlarini yopish. Production uchun canonical `AUTH_URL`, Google callback, Neon pool va deployment host sozlamalarini tayyorlash. Tugash sharti: oddiy Google kirishi va student/admin ruxsatlari deployment previewda ishlaydi.
2. **Savol kontenti.** Avval 5–10 savolni mavjud `docs/content/sirius-questions-template.json` formatiga keltirish. Javob, izoh, skill/domain, qiyinlik va manbani saqlash. Mas’ul tekshiruvchi tanlash. Tugash sharti: import preview xatosiz, reviewer tasdiqlagan savollar nashr qilinadi, mashq va natijada to‘g‘ri izoh ko‘rinadi.
3. **Ariza va profil oqimini chuqurlashtirish.** Universitet shortlistidan trackerga o‘tish, faoliyat/awardlarni arizaga ulash, draftlarni izlash va katta ro‘yxatlar uchun sahifalash. Task status, due date va ariza filtrlari. Tugash sharti: bir student ikki universitet arizasini bir-biriga aralashtirmasdan boshqaradi; arxiv/tiklash tarixni saqlaydi.
4. **Shaxsiy hujjatlar.** Storage provayderi, fayl turi/hajmi, signed upload/download, owner authorization va saqlash/o‘chirish siyosati. Hujjatni arizaga ulash. Tugash sharti: boshqa hisob faylini o‘qiy olmaydi; upload xatosi foydalanuvchiga tushunarli; zararli fayl va nomaqbul hajm rad etiladi.
5. **Mentor va kurslar.** Haqiqiy mentorlar, taqvim, konsultatsiya jarayoni va mas’ul tanlanadi. Vazifa → student javobi → mentor feedbacki; keyin video/o‘qish kurslari va progress. Tugash sharti: haqiqiy mavjud sessiya bron qilinadi va feedback faqat tegishli student/mentor uchun ko‘rinadi.
6. **AI yordamchilari.** Provayder hali tanlanmagan. Birinchi bosqichda essay feedback va activity description yordamchisi: rubrika, dalil, tahrir taklifi, aniq narx/limit, server kalitlari, timeout va foydalanish logi. Tugash sharti: original student ovozi saqlanadi, model xatolari ko‘rsatiladi, sample evaluation to‘plami reviewer bilan baholanadi. Admission-chance foizi validatsiyasiz chiqarilmaydi.
7. **To‘lov va community.** To‘lov hozir ulanmagan. Provayder va tariflar → webhook imzosi/idempotency → entitlement → bekor qilish/qaytarish → billing UI. Community uchun moderatsiya, shikoyat va bloklash talab etiladi. Tugash sharti: sandbox to‘lovi/kutilmagan webhook/replay sinovlari o‘tadi; odamlar xabarlari avtomatik yuborilmaydi.
8. **Production yuklama va tiklash.** Quyidagi load/soak rejasi, xatolar monitoringi, backup hamda isolated restore rehearsal. Tugash sharti: belgilangan yuklamada yo‘qolgan yozish yoki hisoblararo oqish bo‘lmaydi; rollback va ma’lumotni tiklash amalda tekshiriladi.

Sizdan keyin kerak bo‘ladiganlar: savollarning 5–10 JSON namunasi; tekshiruvchi shaxs; AI/to‘lov/storage xizmatlari bo‘yicha tanlov; mentor/kurs bo‘lsa ularning mavjud materiallari. Maxfiy kalitlar chatga emas, tegishli lokal/deployment secret maydonlariga qo‘yiladi.

## Bajarilgan testlar va qolgan stress rejasi

16 faylda 232 avtomatik test: ma’lumot egaligi, parallel save/grade, versiya, kontent ruxsatlari va mavjud SAT oqimlari. Lint, typecheck va production build tekshiruvlari alohida. Brauzerda oddiy Google admin kirishi, student menyusida admin havolalari yo‘qligi, mobil drawer, yangi editor/Insights/Analysis/qo‘llanma, UZ/EN va asosiy sahifalar ko‘rildi.

Neon devda qisqa contention sinovi: 8 owner + 8 foreign fixture; 2 fixture worker; 6 parallel competing writer; 3 revision round. 144 essay yozishi + 144 application yozishi + 96 overview o‘qishi + 40 HTTP authorization so‘rovi. 232 assertion o‘tdi, fixture cleanup tekshirildi. Stress client pool 8, app Neon default pool 4. Jami 127.59 soniya. Essay p95 2893 ms; ariza p95 3393 ms; overview p95 1432 ms; `/explore` dev HTTP p95 4455 ms. Bu raqamlar production SLA yoki foydalanuvchi sig‘imi emas. [Mashina hisobot](../workspace-stress-latest.json)

Birinchi urinishlarda tranzaksiya navbati va appning bir ulanishli pooli vaqt yetishmasligini ko‘rsatdi. Networked workspace tranzaksiyalarida maxWait 10s/timeout 15s, Neon uchun default pool 4 qilindi; PGlite default 1 bo‘lib qoladi. Qayta sinov yuqoridagi natija bilan o‘tdi.

Qolgan sinovlar:

Qisqa sinovni qayta bajarish: `npx tsx scripts/stress-workspaces.ts --dev-host=<tasdiqlangan-dev-host> --origin=http://localhost:3000 --server-mode=dev`. Skript `DATABASE_ENV=dev`, mos Neon host va faqat localhost HTTP manzilini talab qiladi. Production preview sinovida mode alohida `production` bo‘ladi; bazasi baribir tasdiqlangan disposable dev branch bo‘lishi kerak.

- Production previewga oddiy login: local production `AUTH_URL` yo‘qligida UntrustedHost berdi. Yangi sozlama bilan serverni boshlash avtomatik tasdiqlash tekshiruvida rad etildi; devdagi testlar davom ettirildi. [Auth.js izohi](https://authjs.dev/reference/core/errors#untrustedhost)
- Sintetik studentlar bilan read-heavy, mixed va write-heavy yuklamalar: 10 → 25 → 50 concurrent user; har pog‘ona kamida 5 daqiqa. Avval kichik instance va query/memory/pool navbatini o‘lchash; maqsadni o‘lchov asosida belgilash.
- 30–60 daqiqa soak; bosqichlar orasida fixture cleanup; loglarda token/shaxsiy matn chiqmasligini tekshirish.
- SAT: save/submit takrori, deadline, module transition, refresh/resume, bir xil javobning parallel jo‘natilishi; draft restore/archive va import/export yuklamasi.
- Tarmoq uzilishi, Neon sovuq start, storage/AI timeout va webhook replay; xatolikdan so‘ng takroriy amal ikki yozuv yaratmasligi.
- Backupni alohida test bazaga tiklash, yozuv/versiya/eventlar yaxlitligi va foydalanuvchi chegaralarini qayta tekshirish.
